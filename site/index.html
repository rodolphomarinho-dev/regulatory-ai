04 / EVALS IN THE WORKFLOW

Five layers.
One accountable decision.

I check the work while it runs and review the final result.
Material discrepancies come back to me and the Regulatory team.

  1. 01 / COMPONENTS

    Check the parts.

    Sources, versions, tool results and output contracts. Does each part do its job?

  2. 02 / TRAJECTORY

    Check the route.

    Inspect the steps and handoffs. Did the agent follow the source gates and pause when it should?

  3. 03 / OUTCOME

    Check the result.

    Test support and completeness. What did the output get wrong, invent or leave out?

  4. 04 / SYSTEM MONITORING

    Watch for change.

    Track recurring failures and changing behavior across runs. Feed useful signals back to the main agent.

  5. 05 / HUMAN REGULATORY REVIEW

    Make the call.

    I review the final output and discuss material discrepancies with Regulatory before deciding what to use.

I use TypeSafe System One Models (Jev) at layers 3 and 4 for typed evaluation decisions. The signal informs the review; confidence does not guarantee that an individual decision is correct.

WHEN A MATERIAL DISCREPANCY APPEARS

Signal → pause → review the evidence.

The eval sends the finding back to the main agent. I review the evidence with Regulatory, choose a next step and review the final output after any rerun.

  1. Revise the mappingCorrect the supported mismatch, then rerun.
  2. Document non-applicabilityRecord the evidence and rationale, then rerun.
  3. Hold for a sourceKeep the work paused until the missing evidence is available.

After adjudication, I add useful cases to regression checks. The held-out evaluation set stays separate from tuning.

06 / HOW I THINK ABOUT IT

A stronger harness.
A more useful result.

I move between models and tools. The working standard stays: grounded context, inspectable handoffs, meaningful evals and clear ownership.

  1. 01

    Start with the decision.

    What must the team decide? What would change their answer? Make that the intended use.

  2. 02

    Engineer the context.

    Give the agent the right sources, versions and domain definitions. Retrieval needs a source hierarchy.

  3. 03

    Give each agent a job.

    Separate evidence work, specialist challenge and verification. Define the output contract and the handoffs.

  4. 04

    Test what the harness misses.

    Evals should catch unsupported claims, false positives and silent omissions. A convincing answer can still miss the point.

  5. 05

    Design for the people.

    Agree who owns the sources, who reviews the output and how feedback improves the next run.
