05 / HOW I THINK ABOUT IT

A stronger harness.
A more useful result.

I move between models and tools. The working standard stays: grounded context, inspectable handoffs, meaningful evals and clear ownership.

  1. 01

    Start with the decision.

    What must the team decide? What would change their answer? Make that the intended use.

  2. 02

    Engineer the context.

    Give the agent the right sources, versions and domain definitions. Retrieval needs a source hierarchy.

  3. 03

    Give each agent a job.

    Separate evidence work, specialist challenge and verification. Define the output contract and the handoffs.

  4. 04

    Test what the harness misses.

    Evals should catch unsupported claims, false positives and silent omissions. A convincing answer can still miss the point.

  5. 05

    Design for the people.

    Agree who owns the sources, who reviews the output and how feedback improves the next run.
